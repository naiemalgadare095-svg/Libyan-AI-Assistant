# مساعدي AI — 0.7.0-personal

نسخة Android قابلة للبناء والتجربة، مطورة من النموذج الموجود في المستودع (0.1.0، المرجع 9189a67). ليست إصدار v1.0 النهائي، ولا تمثل اكتمال وثيقة المتطلبات. لم يتوفر كود v0.4.2 ضمن المستودع عند المراجعة.

## مراجعة النسخة الشخصية 0.7.0

أدوات تحكم موسعة ولوحة عائمة قابلة للسحب والطي، نموذج رسائل ومكالمات، واقتراحات خطط AI اختيارية للمراجعة. تحسّن إلغاء الطلبات وعزل نتائج الصوت والتعامل مع البيانات التالفة. الصلاحيات وقدرات قراءة الشاشة لم تتغير. راجع [تقرير المراجعة](DESIGN_REVIEW.md) و[حالة المتطلبات](REQUIREMENTS_STATUS.md).

## الوضع الهجين

- أوامر الجهاز الأساسية تظل محلية ولا تحتاج حساب API أو اتصال إنترنت.
- إضافة محادثة نصية حرة عبر OpenAI Responses API، بالنموذج الافتراضي `gpt-4.1-mini` القابل للتعديل.
- من الإعدادات ← إعداد اتصال AI، أدخل مفتاح API شخصيًا لهذا الهاتف. المفتاح غير مضمّن في APK أو المستودع؛ يحفظ مشفرًا بـ AES-GCM ومفتاح Android Keystore. هذه نسخة تجربة شخصية BYOK، وليست توزيع تطبيق بمفتاح مشترك. النشر العام يحتاج بوابة خدمة وسياسة وصول وتكاليف مناسبة.
- كل طلب يحتاج موافقة داخل التطبيق توضح النص والوجهة وأن آخر 8 رسائل من المحادثة قد ترفق. لا تُرفق التسجيلات أو جهات الاتصال أو سجل المهام. استخدام حساب API قد يكون مدفوعًا، ويتطلب توفر الخدمة والموديل للحساب والمنطقة.
- سياق المحادثة في الذاكرة فقط، بحد 8 رسائل، ويُمسح بالخروج أو زر المسح. يرسل الطلب `store:false`، وهو لا يضمن انعدام احتفاظ المزود ببيانات الأمان أو التشغيل.
- المحادثة للقراءة والنطق فقط. الزر المستقل لاقتراح خطة يتحقق محليًا من الرد المنظم ويعرضه للمراجعة دون تنفيذ تلقائي. يظل تنفيذ الجهاز خاضعًا لخطوة المستخدم والتأكيد.
- فشل الشبكة أو المفتاح لا يؤدي إلى إعادة إرسال تلقائية أو تعطيل الأوامر المحلية.
- إصلاح توقف الاستماع بعد فشل TTS، وتحسين كلمة التنبيه مع التشكيل وعلامات الترقيم، وضبط الخمول الفعلي.

تم اختبار التكامل بطلبات وهمية؛ لا يوجد اختبار حي بحساب API أو هاتف فعلي ضمن التسليم. لا ترسل مفتاحك في المحادثة أو تقارير الأعطال. لحذفه استخدم إعداد اتصال AI ← حذف المفتاح أو حذف بيانات التطبيق؛ إلغاء صلاحية المفتاح لدى المزود يتم من حسابك هناك.

## تحديث الواجهة 0.5.1

- أربع شاشات واضحة: المساعد، التحكم، سجل المهام، والإعدادات، مع شريط تنقل ثابت.
- تصميم داكن بدرجات كحلية ولمسات نعناعية، وبطاقات مستديرة وتباين واضح.
- زر صوتي بارز، أمثلة سريعة، ومحرر للأوامر ثم بطاقة خطة ومراجعة.
- إبراز انتظار التأكيد دون تغيير مهلة أو صلاحيات التنفيذ.
- سجل ببطاقات مستقلة وحالة فارغة، وإعدادات مجمعة مع شرح لكل خيار.
- لغة الصوت محفوظة محليًا، ودعم RTL، وإعلانات حالة لقارئ الشاشة، وأهداف لمس 48dp أو أكثر.
- صور الواجهة من تصيير Android عبر Robolectric، وليست صور هاتف فعلي. تتوفر في `docs/screenshots/`.

## تجربة سريعة

1. ثبّت APK على Android 8.0 أو أحدث. التعرف الصوتي المحلي يتطلب Android 12 أو أحدث ومحركًا يدعم اللغة.
2. ابدأ بالكتابة، ولا تمنح صلاحيات لا تحتاجها. راجع الخطة ثم نفذ الخطوة التالية.
3. للأسماء، امنح إذن جهات الاتصال أو احفظ لقبًا ورقمًا من داخل التطبيق. عند تعدد الأسماء اختر المستلم والرقم بنفسك.
4. الاتصال المباشر يحتاج إذن الهاتف وتأكيدًا جديدًا خلال 30 ثانية. استخدم رقمًا تجريبيًا مأذونًا وتوقع تكلفة الاتصال.
5. WhatsApp وSMS يفتحان **مسودات فقط**. الإرسال النهائي من التطبيق الآخر. لواتساب استخدم رقمًا دوليًا يبدأ بـ +.

أمثلة:

```text
افتح يوتيوب ثم ديرلي منبه الساعة 6:30 الصبح
اتصل على أحمد
call Sara
ابعت SMS إلى أحمد "بنتأخر"
send WhatsApp to Sara "I am late"
```

نص الرسالة بين علامتي تنصيص؛ لا تُنفذ أوامر داخل النص. فشل فهم خطوة يمنع إنشاء الخطة كلها. بعد فتح تطبيق خارجي ارجع لمساعدي وتحقق من النتيجة قبل متابعة الخطوة التالية. لا يعيد التطبيق إرسال إجراء تلقائيًا.

## الصوت والتحكم

- محادثة اختيارية داخل التطبيق؛ اللغة الليبية أو الإنجليزية حسب محرك الهاتف. تحليل أوامر الجهاز محلي بقواعد محددة؛ المحادثة الحرة عبر الخدمة السحابية بعد الإعداد والموافقة.
- «يا مساعدي» تنبيه تجريبي عبر محرك التعرف أثناء بقاء التطبيق ظاهرًا. ليس محرك كشف دائمًا منخفض الاستهلاك.
- الوضع المحلي لا يتحول للشبكة بصمت. إذا لم تتوفر اللغة أو الخدمة استخدم الكتابة. محرك الصوت العام قد يعالج الصوت عند مزوده بعد موافقتك.
- الصوت المنطوق من المساعد يستخدم صوت TTS محليًا فقط؛ إذا لم يتوفر يُعرض الرد نصيًا. الاستماع معطل أثناء الرد لمنع تأكيد المساعد لنفسه. المقاطعة أثناء النطق بالزر، وليست محادثة مزدوجة الاتجاه.
- الاستماع يتوقف بالخروج أو قفل الشاشة وبعد دقيقة خمول. لا خدمة خلفية أو وعد بالعمل الدائم أو فتح تلقائي للقفل.
- خدمة Accessibility اختيارية ومحدودة بالرجوع والرئيسية والتمرير، عبر أوامر صريحة ولوحة عائمة. لا تقرأ الشاشة ولا تضغط إرسال. يتطلب تفعيلها موافقة وإعدادًا يدويًا في Android.

## البيانات والتراجع

لا تُحفظ التسجيلات أو نصوص أوامر الجهاز أو محتوى الرسائل في السجل. رسائل AI وسياقها ترسل فقط بعد الموافقة، وتبقى محليًا في الذاكرة المؤقتة حتى الخروج. السجل محلي بحد 100 حدث و30 يومًا، ويحتوي ملخصات بلا أسماء أو أرقام أو محتوى رسائل. الألقاب محلية، وتخضع لحماية مساحة التطبيق في Android؛ لا ندّعي تشفيرًا تطبيقيًا مستقلًا. النسخ الاحتياطي والنقل مستبعدان. زر الحذف يمحو السجل والألقاب والإعدادات. قد يحتفظ محرك الصوت الخارجي ببيانات وفق سياسته عند اختيار الوضع غير المحلي.

التراجع يلغي الخطوات غير المنفذة فقط؛ لا يسحب اتصالًا بدأ أو رسالة أرسلت من تطبيق آخر. الخطط والتأكيدات غير محفوظة بعد إعادة إنشاء الواجهة، منعًا لاستئناف إجراء حساس دون مراجعة. السجل محفوظ بعد إعادة التشغيل.

## البناء والتحقق

Java 17 + Android SDK 35 + Gradle 8.9 (wrapper). اضبط `ANDROID_HOME` أو `local.properties` ثم:

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

على Windows استخدم `gradlew.bat`. الناتج `app/build/outputs/apk/debug/app-debug.apk` بتوقيع Debug للتجربة، غير مخصص للنشر في المتجر. لا تُضمّن مفاتيح خاصة في المستودع.
