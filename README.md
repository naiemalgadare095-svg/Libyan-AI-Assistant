# مساعدي AI — Android MVP 0.1

مشروع مصدر أولي لهاتف Samsung Galaxy A15. **لم يُبنَ أو يُختبر على هاتف فعلي**.

## الوظائف المتوفرة في الكود
- واجهة عربية باستخدام Jetpack Compose.
- التعرف على الكلام عبر واجهة Android المتاحة على الهاتف (ar-LY كتفضيل، جودة اللهجة تعتمد على المحرك المثبت).
- تفسير أولي ومحدود لأوامر المنبهات وفتح YouTube وWhatsApp.
- فتح واجهات الاتصال والرسائل دون إرسال أو إجراء مكالمة تلقائياً.
- طلب صلاحية الميكروفون عند الحاجة.

## غير متوفر بعد
- لا يوجد اتصال OpenAI API أو LLM؛ الفهم يعتمد على قواعد بسيطة.
- لا يوجد تذكير محلي أو قاعدة بيانات أو سجل مهام أو خدمة مساعد افتراضي.
- لا توجد أتمتة واتساب أو تحكم شامل بالشاشة.
- كلمة «بكرة» ليست تاريخاً محفوظاً؛ طلب المنبه يستخدم الساعة والدقائق فقط، ويجب مراجعة توقيت المنبه في تطبيق الساعة.
- لا يوجد تحقق مستقل من إنشاء المنبه.

## البناء
1. افتح المجلد في Android Studio (JDK 17، Android SDK 35).
2. انتظر Gradle Sync لتنزيل الاعتمادات من الإنترنت.
3. وصّل الهاتف عبر USB مع تفعيل USB debugging أو استخدم جهاز اختبار.
4. اختر Run. أو Build > Build APK(s) لإنشاء APK تجريبي.

لا تضف مفاتيح API إلى APK. عند إضافة الذكاء الاصطناعي نحتاج وسيطاً آمناً.

## البناء السحابي باستخدام GitHub Actions
1. أنشئ مستودع GitHub **خاصاً (Private)**، وارفع محتويات مجلد `LibyanAIAssistant` إلى جذر المستودع (وليس المجلد الأب).
2. من تبويب **Actions** افتح **Build Android APK** واختر **Run workflow**. كذلك يعمل البناء تلقائياً عند الدفع إلى الفرع `main`.
3. انتظر نجاح المهمة ثم نزّل `LibyanAIAssistant-debug-apk` من قسم **Artifacts**.
4. فك ملف ZIP الناتج وثبّت `app-debug.apk` على هاتفك بعد مراجعة مصدره. قد تحتاج السماح بالتثبيت من المصدر الذي فتحت منه الملف.

**مهم:** هذا APK تجريبي بتوقيع debug وليس إصدار إنتاج. لا توجد مفاتيح API ضمن المشروع. لم يتم اختبار البناء السحابي أو تثبيت APK على الجهاز حتى الآن.
